# Tic-Tac-Toe (Tkinter)
Dieses Projekt implementiert eine einzelne Runde des Spiels Tic-Tac-Toe mit einer grafischen Benutzeroberfläche.
Die visuelle Darstellung wurde mit Tkinter umgesetzt, während ttkbootstrap für ein modernes Theme verwendet wird.

### Spielbeschreibung
* Zwei Spieler spielen abwechselnd
* Spieler ❌ beginnt
* Spieler ⭕ folgt
* Das Spiel endet, sobald ein Spieler drei Symbole in einer Reihe, Spalte oder Diagonale platziert hat
* Falls alle Felder belegt sind und kein Gewinner feststeht, endet das Spiel unentschieden - "Draw!"
* Das Spiel ist für eine einzelne Runde ausgelegt und speichert keine Punktestände

### Technologien
* Python 3
* Tkinter (GUI)
* ttkbootstrap (Theme: morph)

### Steuerung
* Klicke mit der Maus auf ein Feld, um deinen Spielzug zu machen
* Nach Spielende startet automatisch eine neue Runde
